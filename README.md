# Palmer Páginas

Páginas públicas que as plataformas exigem dos apps de Rafael Fraiha: página inicial, política de privacidade e
termos de uso do app OAuth "Recorte Ligeiro" (Google Cloud, projeto `ornate-bebop-512023-t4`).

Publicadas pelo GitHub Pages em https://rafaelfraiha2-afk.github.io/palmer-paginas/ a partir da raiz da branch
`main`. HTML puro, sem script nem rastreamento.

Criado em 2026-11-01 para tirar o app do modo "Testando" (as autorizações venciam a cada 7 dias).
